# Fintech Review Analytics

&gt; **10 Academy Week 2 Challenge** — Customer Experience Analytics for Ethiopian Fintech Apps

## Overview

This repository contains a complete analytics pipeline that scrapes, processes, analyzes, and visualizes Google Play Store reviews for three Ethiopian banks:

- **Commercial Bank of Ethiopia (CBE)**
- **Bank of Abyssinia (BOA)**
- **Dashen Bank**

The pipeline transforms raw user feedback into actionable insights for product teams.
